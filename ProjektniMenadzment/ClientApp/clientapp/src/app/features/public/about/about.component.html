O aplikaciji

Sistem za upravljanje projektima namenjen timovima koji rade na razvoju video igara — od planiranja i organizacije do praćenja napretka i komunikacije unutar tima.

Zašto ova aplikacija?

Razvoj video igara je složen proces koji zahteva koordinaciju između dizajnera, programera, testera i producenata. Generički alati za upravljanje projektima često nisu prilagođeni specifičnostima game-dev industrije.

Ova aplikacija je nastala kao odgovor na taj problem — sistem koji razume koncepte poput build verzija, tipova zadataka specifičnih za igre i uloga unutar razvojnog tima.

Ključne funkcionalnosti

✓
Upravljanje projektima

Kreiranje i praćenje projekata sa detaljnim pregledima statusa i rokova.

✓
Sistem zadataka

Zadaci sa tipovima (bug, feature, dizajn, optimizacija), prioritetima i dodeljivanjem članovima.

✓
Upravljanje timom

Uloge na projektu — administrator, projektni menadžer i član — sa različitim nivoima pristupa.

✓
Evidencija resursa

Praćenje softverskih i hardverskih resursa angažovanih na projektu.

✓
Build verzije

Beleženje i praćenje build verzija projekta tokom razvojnog ciklusa.

✓
Komentari na zadacima

Diskusija i komunikacija direktno vezana za konkretne zadatke.

Tehnologije

Aplikacija je razvijena kao deo diplomskog rada koristeći moderne web tehnologije:

  • Frontend: Angular 19, TypeScript, SCSS
  • Backend: ASP.NET Core 8, C#
  • Baza podataka: Microsoft SQL Server, Entity Framework Core
  • Autentifikacija: JWT tokeni
  • Upravljanje korisnicima: ASP.NET Identity
